# 德州扑克

完全本地运行的2–11 人无限注德州扑克练习桌。无框架、无第三方运行依赖、无 CDN、无 API、无账号。

## 启动

直接用现代浏览器打开本目录的 `index.html` 即可游玩；双击 HTML 不需要服务器或网络。

也可以运行 `bash start.sh`，然后在浏览器打开 `http://127.0.0.1:8787`。此方式只监听本机，需要 Python 3；按 Ctrl+C 停止。

## 功能

- 人数可选：一位人类玩家 + 1–10 位 AI（共 2–11 人）。点击牌桌上方的人数 / 模式按钮，新建牌桌生效。
- 标准牌 52 张；短牌 36 张（6–A），同花大于葫芦、顺子大于三条，A6789 为最小顺子。两种模式均采用小盲 10 / 大盲 20，短牌为大小盲练习版，不使用全员前注 / 按钮盲。
- 起始筹码可选 1,000 / 2,000 / 4,000，筹码归零的玩家离桌，剩余两人时自动采用单挑盲注与行动顺序。
- 入门、标准、进阶、专家四档难度，首次打开默认专家。每个 AI 的性格默认随机抽取紧凶、松凶、均衡、稳健或跟注型，也可手动指定。抽取结果在本桌内保持，标签、座位颜色与复盘不透露结果。
- 弃牌、过牌、跟注、加注、全下；按钮位轮转、最小加注、不足额全下后的加注权、主池与边池、平分及奇数筹码。
- 半池、四分之三池、满池等下注快捷操作，数值输入与滑块。
- 每个 AI 的打法多样性均可单独设置为低 / 中 / 高 / 随机，默认随机。低档保留鲜明性格，高档弱化固定性格，增加合理行动与下注尺寸变化；与 AI 难度独立。随机为每个 AI 独立抽取低、中、高，在本桌内保持。修改从下一手生效，新建牌桌重新抽取。
- 本机 Web Audio 合成发牌、筹码、过牌、弃牌、行动提醒与结算音效，无需下载音频。首次点击或按键后启用，顶部可静音，新建牌桌内可调音量；浏览器不支持音效时仍可游玩。
- AI 行动节奏可调，等待期间可以暂停。弹窗打开时暂停 AI，关闭后继续。
- 本地保存设置与最近 20 手牌局，提供公开行动记录及 AI 决策估算回看。刷新页面会新开一桌，不恢复正在进行的手牌。
- 桌面、平板与手机布局，键盘操作与减少动态效果偏好。

## AI 设计

`engine.js` 中的 `observation()` 是信息边界：只输出该 AI 的两张底牌、公共牌、合法动作、公开行动与统计；不输出其他玩家底牌、剩余牌堆、随机数状态。AI 在 `ai.js` 运行，无法从参数读取隐藏信息。

1. **起手牌与位置**：按牌对、高张、同花、连接性等构建启发式起手牌排名，位置、加注次数与打法决定开池和再加注范围。
2. **范围推断**：枚举所有可能两张组合，去除已知牌；基于对手入池率及公开的下注、跟注、过牌历史更新组合权重。用历史对应街道的公共牌更新似然。
3. **蒙特卡洛估计**：从加权对手范围抽取不冲突的底牌，并模拟剩余公共牌，估计包含平分的底池份额。各档默认 100 / 320 / 800 / 1,800 次。进阶和专家档在单挑河牌精确遍历标准牌的全部 990 种或短牌的全部 406 种可能对手底牌，以消除该场景的抽样误差；范围建模误差仍然存在。
4. **行动选择**：综合底池赔率、可争夺底池大小、位置、权益实现率、有效筹码、牌面和听牌，选择价值下注、跟注、半诈唬或弃牌。
5. **混合策略与适应**：使用概率化下注尺寸与诈唬，基于经过先验平滑的公开弃牌/跟注统计适当调整，多人底池降低诈唬频率。统计按当前牌桌累积，新桌重置。

专家档仍是启发式策略和范围模拟，**不是 GTO / CFR 求解器，没有职业级实力保证，也没有与 GPT 模型对战的实力基准**。增加模拟次数主要降低抽样噪声，不会消除策略模型误差。多人边池决策使用简化的权益模型；边池结算则按实际贡献与最佳五张牌完成。

## 隐私与离线

所有代码、样式、花色、纹理均随文件附带。页面的内容安全策略设有 `connect-src 'none'`。没有遥测、远程字体、接口请求或在线模型。浏览器本地存储不可用时仍能游玩，但不能跨刷新保留设置和记录。`file://` 下本地存储行为由浏览器决定；如需更稳定的保存，可使用本地启动脚本。

牌后只展示未弃牌的摊牌玩家底牌和人类玩家自己的底牌；弃牌 AI 的底牌不写入历史。随机洗牌用于娱乐练习，采用浏览器 `Math.random()`，不用于任何真实资金场景。

## 操作

- `F` 弃牌；`C` 过牌或跟注；`R` 按当前金额加注；`N` 下一手。
- 输入或打开弹窗时不触发游戏快捷键。
- “加注到”是当前下注轮累计投入总额，不是额外增加的金额。
- 对手打法修改从下一手生效；难度与节奏修改从下一次 AI 决策生效。
- 新建牌桌会重置本桌筹码与统计，已完成牌局的本地历史仍保留。

## 文件

- `index.html`：页面结构。
- `style.css`：本地样式与响应式布局。
- `engine.js`：发牌、牌型评估、下注轮次、结算和信息边界。
- `ai.js`：起手牌模型、范围推断、胜率模拟、决策策略。
- `app.js`：界面交互、AI 调度、设置与历史。
- `sound.js`：离线合成音效、交互后初始化、音量和静音。
- `tests/run.cjs`：无需第三方库的自动化测试。

本项目没有构建步骤。修改源码后刷新浏览器即可。

## 跟注与防守更新验证

修复强起手牌在加注权未重新开放或面对全下、无法加注时错误弃牌的问题。跟注先独立评估，再考虑合法加注。适度放宽未加注底池的入池范围与低价盲位防守；翻牌后按跟注价格调整未来街道折扣，避免对小额下注同时施加过大的折扣和固定门槛。保留弱牌与昂贵跟注的弃牌判断。

36 项自动化测试通过，新增覆盖未重新开放加注权、面对全下以及小额下注防守与昂贵跟注的区别。另以固定种子、随机性格与随机多样性、专家参数（每次 300 次模拟用于批量验证）比较更新前后，两种模式各 2 / 6 / 11 人桌各 100 手。标准六人桌进入翻牌的手数由 61 / 100 增至 72 / 100，面对下注的弃牌比例由约 72% 降至 70%；短牌六人桌进入翻牌的手数由 67 / 100 增至 78 / 100。不同决策会改变后续抽样轨迹，以上仅为小样本行为检查，不是胜率或强度证明；实际专家档仍默认 1,800 次模拟。
